# Research Questions

## Research Goal

Document how the three repositories currently perform engineering delivery, security assessment, evaluation, and orchestration. Distinguish actual code paths from documented instructions.

## Questions

1. How do the upstream dev-team slash skills and Python orchestrator dispatch agents, persist work, resume, review and publish across task sizes and repositories? (analyze)
2. How does security-assessment execute tool scans, agent judgments, suppression, cross-repository analysis, red-team authorization and report checks? (analyze)

4. How does Adyton skills adapt task records, multi-repository delivery, GitLab, Jira, Slack, security checks and runtime adapters? (analyze)
5. Which hook events and Git admission gates are registered in each repository, what decision data do they use, and what are their failure and bypass paths? (locate)
6. Which evaluations measure live agent outputs, which use fixtures or archived baselines, and how are cost, recall and acceptance scored? (locate)
7. How are phase and worker concurrency, model selection, artifact transfer and project boundaries represented and tested in each system? (analyze)
