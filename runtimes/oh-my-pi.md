# Oh My Pi

## Skill notes

Invoke a skill by typing `/<name>` in the Oh My Pi prompt, for example `/create-plan @03-plan-verbose-flag-cli.md`.
Child workers: call the `task` tool with one item `{ "agent": "agent-<role>", "task": "<assignment>" }`; the result auto-delivers when the worker yields. Read its final message before using any claim.

## Install

`npx github:MarkTripoli/skills oh-my-pi` performs these steps (add `--project` for one repository, `--dry-run` to look first); by hand:

1. Build the tree: `npm run build -- --runtime oh-my-pi` (writes `dist/oh-my-pi/`).
2. Skills: `cp -R dist/oh-my-pi/skills/* ~/.omp/agent/skills/` (the native user directory, which wins over same-named skills from other directories; `~/.agents/skills/` also works).
3. Workers: `cp dist/oh-my-pi/agents/*.md ~/.omp/agent/agents/` for every project, or `cp dist/oh-my-pi/agents/*.md <repo>/.omp/agents/` for one project. Project agents win over user agents with the same name.
4. Start a new session; `/agents` lists the workers and `/` lists the skills.

## Archon

Archon has no Oh My Pi provider. Use the `-omp` pack flavor under `.archon/workflows/delivery-omp/` (`delivery-full-omp`, `delivery-bugfix-omp`, ...): the same DAG, gates, and loops as the native packs, with every AI node rewritten as a `bash:` node that reads the prompt from a bash 3.2-safe heredoc and runs `omp -p --auto-approve --no-session --max-time=45m "$prompt"`. `omp` must be on `PATH` for the user running Archon, and `omp -p` must print only the final answer on stdout: nothing validates it, and the JSON-answer nodes (`review-code`, `reproduce-bug`, whose schema the generator appends to the prompt) fail the next node when stdout is not a JSON object. The installer writes this flavor when `oh-my-pi` is a target (`npx github:MarkTripoli/skills oh-my-pi`, or detected on `PATH`); the native flavor comes only with Claude Code, Codex, Pi, or portable targets. The flavor is generated by `node scripts/build-packs.mjs`; do not edit it by hand.

What the flavor loses against a native provider: no per-node cost, retry, or idle timeout; `--max-time=45m` is the only bound on a stuck session. Start a run with `archon workflow run delivery-<type>-omp --branch <name> "<request>"`; gates, `--input gates=...`, the steering loop, and the committed task directory work as for the native packs ([workflows/delivery.md](../workflows/delivery.md#steering-a-run)).

The packs read skills from `skills_dir` (`~/.agents/skills` by default). Oh My Pi also reads that directory, so the portable copy works; pass `--input skills_dir=~/.omp/agent/skills` to use the tree built for Oh My Pi, whose worker calls use the `task` tool.
