New `herd-next` skill: inside Herdr, it opens the next delivery phase in its own pane with the handoff command staged, so continuing a task no longer means copying a command into a new session by hand. It also gained an Archon gate mode: given a run id, it opens a review pane at the run's own worktree and attaches `deliver`'s steward there, so a paused Archon run is announced and answered in a pane instead of by a person running Archon commands.
