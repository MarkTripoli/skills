# Word rulings

A good newspaper style guide is mostly an alphabetical list of rulings on individual words. These are the ones that go wrong most often, in US spelling, plus rulings specific to technical text.

Flag a word only when the text uses it in the disputed sense. A correct use of *decimate* is not an error.

## General

| Word | Ruling |
|---|---|
| address (verb) | Vague for a problem. Fix, answer, or tackle |
| aggravate | Make worse. Not annoy |
| alternative | One of two. With more than two: option, choice |
| anticipate | Act in expectation of. Not merely expect |
| beg the question | Assume what is to be proved. Not raise the question |
| community | Overused. Name who you mean |
| compare | With, for differences. To, for likening |
| comprise | The whole comprises the parts. Never "comprised of" |
| crisis | A decisive turning point. Not any difficulty |
| decimate | Kill one in ten. Not destroy |
| dilemma | A choice between two unwelcome options. Not any problem |
| disinterested | Impartial. *Uninterested* means bored |
| enormity | Great wickedness. Not great size |
| famously | If it is famous you need not say so. If not, the word is false |
| flaunt / flout | Flaunt is display. Flout is break a rule |
| fortuitous | By chance. Not fortunate |
| hopefully | Not a sentence adverb. Say who hopes |
| iconic | Exhausted. Say why the thing matters |
| imply / infer | Speakers imply. Listeners infer |
| key (adjective) | Overused. Main, chief, or cut |
| less / fewer | Less for quantity, fewer for number: less memory, fewer allocations |
| literally | Not an intensifier |
| major, massive | Overused. Big, large, and say how large |
| may / might | Might for hypotheticals and past possibility. May for permission and present possibility |
| militate / mitigate | Circumstances militate against. You mitigate an effect |
| ongoing | Continuing, or cut |
| practicable / practical | Practicable is doable. Practical is useful |
| refute | Disprove. One who disagrees denies or rejects |
| situation | Usually redundant. "A crisis situation" is a crisis |
| transpire | Become known. Not happen |
| unique | Absolute. Nothing is very unique |
| viable | Capable of independent life. Overused for feasible |
| while / whilst | While. Never whilst |

## Technical writing

| Word | Ruling |
|---|---|
| allow / enable / let | Software lets a user do something. Enable is for turning a flag on |
| architect (verb) | Not a verb. Design |
| assure / ensure / insure | Assure a person. Ensure an outcome. Insure a risk |
| can / may / must / should | Load-bearing in a spec. Must is a requirement, should a recommendation, may an option. Never swap one for another in an edit |
| deprecated / removed / disabled | Three states. Deprecated still works |
| e.g. / i.e. | In machine-read text and documentation, write "for example" and "that is" |
| execute | Programs and legal documents execute. People run a command |
| leverage, utilize | Use |
| once | Ambiguous between "as soon as" and "one time". Write after or when |
| performant | Not a word in plain use. Say fast and give the number |
| please | Not in an error message or a procedure. Adds a word and no information |
| robust / scalable / seamless | Unmeasurable. Give the limit, the throughput, or the failure mode |
| simply / just / easy / obviously | Delete every one. If it were easy the reader would not be here. These words tell a stuck reader they are stupid |
| since / as | Ambiguous between time and cause. Write because when you mean cause |
| support (verb) | Vague. Say what the thing does with the input |
| valid / invalid | Say what makes it invalid. "Invalid input" is not an error message |
| we / you / the system | One voice per document. In procedures, address the reader: "Run the migration" |
