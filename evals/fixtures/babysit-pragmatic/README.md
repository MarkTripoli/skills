# Decimal CLI

`node src/decimal.mjs <number> [number ...]` sums finite numeric arguments. Decimal, negative and exponent-form inputs retain their numeric value. Invalid input exits with status 2 and prints usage.

Run the required CI check with `node tests/check-decimals.mjs` or `npm test`. It launches the actual CLI for decimal, negative, integer, exponent and invalid-input behavior. No dependencies or build step are required.
